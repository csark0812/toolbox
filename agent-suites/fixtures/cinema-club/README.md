# Cinema club

Ticket prices for the Lantern community cinema. `data/screenings.json` lists this month's screenings. Matinees (starting before 17:00) are £7.50 and evening screenings £10.00.

## Usage

```
npm run prices   # this month's screenings and prices
npm test
```

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `lantern-cinema/tickets`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
