# Event badges

Name badges for Northern Data Day 2026. A static page: open `index.html` in a browser to check the list on screen, then print it onto the badge stock with the browser's Print button.

The badge stock is the LabelCo LC10-9054 sheet: A4 portrait, ten die-cut badges per sheet in two columns of five. Each badge is 90mm wide and 54mm high, with no gap between them, so the badges fill 180 × 270mm; the sheet has a 15mm margin left and right and 13.5mm top and bottom. The dashed edge we print is a cutting guide for when we run out of stock and use plain paper, so it has to sit on the die-cut line.

The coloured strip along the bottom of each badge shows the person's role, so the door staff can tell speakers, sponsors, staff and attendees apart from across the room.

Styles are in `styles.css`, with the tokens at the top. `npm test` checks the stylesheet parses and every attendee has a badge.
