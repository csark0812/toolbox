# Choir register

Attendance for the Wednesday rehearsals of the Eastgate Community Choir. `data/members.json` lists the members with their section and the date they joined; `data/rehearsals.json` lists each rehearsal this term and who was there.

`npm run report` prints each member's attendance this term: rehearsals attended, rehearsals they could have attended, and the percentage. The section leaders use it to decide who sings in the winter concert. `npm test` runs the tests.
