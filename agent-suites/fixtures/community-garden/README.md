# Community garden

Yearly bills for the Hollins Lane community garden. `data/plots.json` lists each plot with its holder, its size (1 for a full plot, 0.5 for a half, 0.25 for a quarter) and whether this year's bill is paid.

Rent is £60 for a full plot, £35 for a half and £20 for a quarter. Every plot also pays the water charge of £12 a year.

## Usage

```
npm run plots    # every plot with its bill
npm test
```
