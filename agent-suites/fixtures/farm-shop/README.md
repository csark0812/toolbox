# Farm shop

Orders for the Hollins Farm shop. `data/orders.json` lists this week's collection orders: the customer, whether they're a veg box subscriber, and what they ordered. `data/prices.json` gives each product's price in pence.

## Usage

```
npm run till   # this week's orders with what each customer pays
npm test
```

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `hollins-farm/shop`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
