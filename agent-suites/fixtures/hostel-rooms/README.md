# Hostel rooms

The rooms page for the Kastanienhof hostel in Leipzig. A static page: open `index.html` in a browser. Room names come from the booking system exactly as the front desk types them, in German, and guests quote them when they ring up, so they have to appear in full.

Styles are in `styles.css`; colours and spacing come from the tokens at the top.

`npm test` checks the stylesheet parses.
