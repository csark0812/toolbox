# Rowing club

Outings for Weir Bend Rowing Club. `data/outings.json` lists the week's outings: when each one starts, the boat, its class (`1x` single, `2x` double, `4x` quad, `8+` eight) and the crew.

## Board

The boathouse board lists the week's outings in start order. Each line shows the start, the boat and its class.

## Usage

```
npm run board   # the week's outings for the boathouse board
npm test
```

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `weir-bend/outings`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
