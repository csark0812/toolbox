# Tenpin league

Results for the Thursday night league at Riverside Lanes. `data/games.json` has every game bowled this season: the league night, the bowler and the score sheet as the lane desk typed it in, one frame per space (`X 7/ 9- X -8 8/ -6 X X X81`).

## Usage

```
npm run games   # every game, in the order bowled
npm test
```
