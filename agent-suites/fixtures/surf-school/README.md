# Surf school

The lesson groups for Porthgwyn Surf School. `data/pupils.json` lists who is booked in: each pupil's name, age and level (`beginner`, `improver` or `advanced`), and the lesson pack they bought, if any (its first day and how many days it runs).

## Groups

Each morning the hut prints the day's groups, one line per level with the pupils in it.

## Usage

```
npm run groups   # today's lesson groups
npm test
```

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `porthgwyn/surf-groups`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
