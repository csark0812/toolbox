# Swim club

Squad records for Millbrook Amateur Swimming Club. `data/swimmers.json` has each squad swimmer's date of birth and their best times as the coaches typed them in from the results sheets (`1:05.32`, `33.12`, or `NT` when they have no time). `data/gala.json` is the next open gala and `data/standards.json` its qualifying times for each event and age group.

## Usage

```
npm run swimmers   # every squad swimmer and their date of birth
npm test
```
