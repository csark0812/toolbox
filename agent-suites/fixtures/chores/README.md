# Chores

The chore rota for our shared house. `data/household.json` lists the housemates and the chores; every week each chore moves to the next person. `npm run rota -- <ISO week, e.g. 2026-W42>` prints who does what. `npm test` runs the tests.

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `elm-street/chores`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
