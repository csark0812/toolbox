# Escape rooms

Price quotes for Lockbox Escape Rooms. Every room takes 2 to 10 players and is priced per player (`data/rooms.json`).

## Usage

`npm run quote -- <room> <players> <YYYY-MM-DD>` prints the quote for a booking: one line per charge and the total.

`npm test` runs the tests.

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `lockbox/escape-rooms`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
