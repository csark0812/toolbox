# Market pitches

The Saturday market on Millbrook Green. `data/attendance.csv` is the warden's log of every trader who set up a pitch, by date.

A standard pitch costs £22 a Saturday, collected on the day. Season-pass traders pay £200 a quarter in advance, so they owe nothing on the day. Charity pitches are free.

When a month has five Saturdays, the fifth one is free for every trader. That is the market's thank-you to regulars.

## Usage

```
npm run fees               # pitch fees for 2026 so far
npm run fees -- 2026-03    # one month
npm test
```
