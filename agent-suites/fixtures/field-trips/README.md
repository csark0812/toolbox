# Field trips

Permission slips for school trips. `data/roster.json` is the class roster and `data/slips.json` records which parents have signed for which trip.

`npm run slips -- <trip>` lists the students whose slip for that trip is still missing, by form. `npm test` runs the tests.

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `hillside-primary/field-trips`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
