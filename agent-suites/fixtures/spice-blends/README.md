# Spice blends

The recipe book for Saffron & Salt, a market spice stall. `data/blends.json` holds each house blend as a list of spices with the amount for one jar, written the way the owner writes them on the cards (`1 1/2 tsp`, `2 tbsp` and so on).

## Usage

```
npm run blend -- ras el hanout    # the recipe for one jar
npm test
```
