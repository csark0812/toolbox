# Chess ladder

The club ladder page for the Riverside Chess Club. Open `index.html` in a browser; all styles are in `styles.css`.

The theme menu in the corner sets `data-theme="light"` or `data-theme="dark"` on `<html>`; with no `data-theme` (the "System" choice) the page follows the device's light or dark setting. The two palettes:

| Token          | Light     | Dark      |
| -------------- | --------- | --------- |
| `--bg`         | `#ffffff` | `#0f172a` |
| `--surface`    | `#f1f5f9` | `#1e293b` |
| `--text`       | `#0f172a` | `#e2e8f0` |
| `--muted`      | `#64748b` | `#94a3b8` |
| `--badge-bg`   | `#dbeafe` | `#1e3a8a` |
| `--badge-text` | `#1e3a8a` | `#dbeafe` |

`npm test` runs the stylesheet checks.
