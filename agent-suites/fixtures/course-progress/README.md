# Course progress

Progress tracking for the safety training portal. `npm run progress` prints each learner's progress through their courses from `data/learners.json`; settings live in `config/settings.json`. `npm test` runs the tests.

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `brightpath/course-progress`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
