Streaming uploads

Create a client and open an upload session before sending any bytes.

const session = await lumen.uploads.open({ bucket: 'field-recordings-2026', key: 'site-04/dawn-chorus/raw-take-0012.wav', contentType: 'audio/wav', checksum: 'sha256' })

Chunks must be at least 5 MB except for the last one.

Failed chunks are retried with exponential backoff.

Subscribe to progress events to drive a progress bar.

Every error carries a machine-readable code.
