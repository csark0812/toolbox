# Allotment fees

Annual rent for the plots at Hollin Lane allotments. Rent is 32p per square metre plus a flat £18 water charge. Pensioners get half off the rent and students a quarter off; the water charge is never discounted. Amounts are kept in pence and rounded to the nearest penny once per plot.

`npm run fee -- <plot>` prints one plot's fee. `npm run invoices` prints every plot's fee and the season total for the treasurer. `npm test` runs the tests.
