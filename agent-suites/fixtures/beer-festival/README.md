# Beer festival

Cask list for the Harbourside Beer Festival. `data/casks.json` holds every cask on stillage: the beer, the brewery, its strength (ABV, %), which bar pours it and its style.

## Usage

```
npm run list        # the list pinned up behind the bars
npm run programme   # one line per beer for the printed programme
npm test
```

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `harbourside/beer-festival`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
