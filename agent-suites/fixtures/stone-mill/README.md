# Stone mill

The milling-day schedule for the Hendre Community Mill. Growers book a half-hour slot on the millstones and say roughly how many kilos of grain they're bringing. `data/slots.json` lists Saturday's bookings: the slot time, the grower and the weight.

## Schedule

The volunteer on the mill prints the day's schedule in the morning, one line per slot in time order.

## Usage

```
npm run schedule   # Saturday's milling schedule
npm test
```

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `hendre-mill/milling-day`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
