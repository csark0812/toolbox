# Manuscript stats

Word counts and reading times for the chapters of our travel anthology, in every language it is published in. Our editors' rule: a word is anything between spaces that contains a letter or a digit, and a contraction such as `don't` or `l'été` is one word.

`npm run stats -- <folder>` prints a line per Markdown file (words, sentences, minutes to read at 230 words a minute) and a total. `npm test` runs the tests.
