# Soup kitchen

Cooking days at the St Aidan's Tuesday soup kitchen. `data/soups.json` lists the soups we make, in the order they go out on the serving counter, and `data/batches.json` has every batch: the date, the soup, whether it was served or burnt, and each pot as the cook wrote it on the whiteboard (`8l`, `4.5 l`, `750ml`, `6 pints`).

## Usage

```
npm run batches   # every batch
npm test
```
