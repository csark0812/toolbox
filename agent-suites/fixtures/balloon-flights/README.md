# Balloon flights

Passenger flights for Vale Balloons. `data/flights.json` lists the week's flights: the date, the launch site, dawn or dusk, the basket size and how many seats are booked.

## Usage

```
npm run flights   # the week's flights for the office board
npm test
```

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `vale-balloons/flights`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
