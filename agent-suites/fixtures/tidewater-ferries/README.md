# Tidewater Ferries: timetable and fares page

Tidewater runs three foot-and-bike ferries across the Fal estuary. The brand is fixed by `brand.css`
(colours, typefaces, logo usage); do not change it. Everything else on the page can change.

The timetable data is in `timetable.js`. The page is static: `index.html`, `styles.css`.
