# Cider press

Drop-offs at the Orchard Lane community press, which runs every Saturday in October. Growers bring apples in sacks, crates or the back of the car, someone weighs them on whatever scales are to hand and writes the weight on a tag, and the apples go in the press with everyone else's. `data/drops.json` has one entry per tag: the drop-off id, the date, the grower, the variety and the weight exactly as it was written on the tag.

## Usage

```
npm run drops   # every drop-off
npm test
```
