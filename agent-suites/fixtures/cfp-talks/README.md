# CFP talks

Talk proposals for our regional web conference. `data/submissions.json` is the export from the submission form.

- `npm run cfp -- check` lists proposals whose abstract is over the 120-word limit.
- `npm run cfp -- export` prints every proposal as CSV for the programme committee's spreadsheet.
- `npm run cfp -- speakers` lists each speaker once with how many proposals they sent.

`npm test` runs the tests.
