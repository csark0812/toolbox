# Gym join form

The online join form for Ironworks Gym. A static page: open `index.html` in a browser. Styles are in `styles.css`; colours come from the tokens at the top, with a dark palette for devices set to dark mode.

The small script at the bottom of the page marks a field with `aria-invalid="true"` and shows its error message when someone leaves it invalid, and clears both once it is fixed.

`npm test` checks the stylesheet parses.
