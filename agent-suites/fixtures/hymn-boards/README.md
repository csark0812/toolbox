# Hymn boards

The hymn list for St Aidan's. `data/hymns.json` is the hymn book we use: each hymn's number, its title and how many verses it has. `data/services.json` has the hymns chosen for each Sunday service as the vicar sends them over, for example `372 v1-3,5` for verses 1, 2, 3 and 5 of hymn 372.

## Usage

```
npm run services   # every service and its hymns
npm test
```
