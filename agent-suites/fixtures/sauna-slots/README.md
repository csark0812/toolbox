# Sauna slots

The booking page for the harbour sauna. A static page: open `index.html` in a browser. Each time slot is a button; slots that are full are rendered as `disabled` buttons. Styles are in `styles.css`; colours come from the tokens at the top, including the `--disabled-*` pair the design system uses for anything that can't be used.

`npm test` checks the stylesheet parses.
