# Bin collections

Recycling collection rounds for Ashby parish council. `data/streets.json` gives each street's round as the council writes it (`weekly on Tue`, `fortnightly on Fri from 2026-10-02`). `data/holidays.json` lists the bank holidays when the crews don't go out.

## Usage

```
npm run street -- "Mill Lane"   # a street's collection round
npm test
```
