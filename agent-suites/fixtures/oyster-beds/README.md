# Oyster beds

The Friday pack list for Trelowarren Oyster Farm. Restaurants and shops along the river order oysters for the Friday van, sorted by size into No.1 (largest), No.2 and No.3. `data/orders.json` lists this week's orders: the customer, the grade and how many dozen.

## Pack list

Whoever is in the packing shed on Friday morning prints the pack list, one line per order in the order the van calls.

## Usage

```
npm run packlist   # this Friday's pack list
npm test
```

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `trelowarren/oyster-orders`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
