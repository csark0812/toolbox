# Minibus log

Fenwick Community Transport lends its minibus to local groups and bills them 40p a mile. `data/trips.json` is this month's trip log. Drivers who use the tablet log their miles directly; trips from the paper logbook are copied in by the office afterwards.

## Usage

```
npm run invoice   # miles and amount owed per group this month
npm run report    # total miles for the trustees' report
npm test
```
