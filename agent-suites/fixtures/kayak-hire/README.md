# Kayak hire

Bookings and bills for the boathouse at Hollow Mere. People hire a single kayak, a double kayak or a stand-up paddleboard for a few hours.

Prices are per started hour: £12 for a single kayak, £18 for a double and £14 for a paddleboard. Everyone pays a £20 deposit, refunded when the craft comes back. Craft returned after the due time pay a late fee of £5 for every started 15 minutes, taken from the deposit.

- `npm run bookings` lists every booking.
- `npm run bill -- <booking id>` prints a booking's bill.

`npm test` runs the tests.
