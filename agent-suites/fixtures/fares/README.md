# Fares

Fare quotes for the Cobalt Cabs app. A fare is a base charge plus a per-kilometre and a per-minute rate, in whole cents. `npm run quote -- <km> <minutes>` prints a quote. Distances come from `src/distance.mjs`. `npm test` runs the tests.

This sandbox is offline. Use `tools/gh` (an offline mirror of this repository's GitHub, `cobalt-cabs/fares`) wherever you would use `gh`. The `origin` remote is the mirror's Git server.
