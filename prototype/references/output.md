User-facing blocks must use clear English: short sentences, concrete subjects and verbs, and one meaning per sentence.

```markdown
## Prototype

**Question:** [one line]
**Mode:** throwaway | keep-skeleton
**Branch:** logic | UI
**Run:** `[one command]`

### Verdict

[what we learned — promote / discard / more grill]

### What to do next

- [grill, tdd, handoff, discard cleanup]
```
