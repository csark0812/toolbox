# Council interaction patterns

<!-- source-of-truth: starter interaction router for task-persona councils. -->
<!-- doc-meta: owner=eng | last-reviewed=2026-10-15 -->

Read this file when an independent panel is not enough. These patterns are a starter set, not a closed taxonomy.

Choose one primary pattern. Add at most one focused follow-up when a named conflict or evidence gap can change the result. First views stay independent unless the selected pattern starts after an independent round.

| Pattern                  | Use when                                                  | Structure                                                                                                                                                                           |
| ------------------------ | --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Independent panel**    | A review needs different risks or evidence sources        | Personas answer independently. The coordinator compares their evidence.                                                                                                             |
| **Structured challenge** | An existing proposal needs attack and defense             | Challenger and defender start independently. Add one response round only for material unresolved claims.                                                                            |
| **Competing proposals**  | Complete alternatives need comparison                     | Each persona develops or tests one alternative against shared criteria.                                                                                                             |
| **Nominal ideation**     | The task needs options before evaluation                  | Generate independently. Cluster duplicates. Then assess or rank the remaining options.                                                                                              |
| **Delphi revision**      | Estimates or policy judgments need controlled convergence | Collect independent estimates. Share a neutral summary. Allow one revision. Keep the range and dissent.                                                                             |
| **Pick and graft**       | Several complete candidates exist for one artifact        | Same brief for every member. Score each candidate per criterion against a rubric members never see. Pick one base, then port one or two ideas from each other candidate coherently. |
| **Socratic seminar**     | Assumptions, definitions, or reasoning need clarification | Personas ask evidence-led questions. The coordinator records clarified premises and unresolved questions.                                                                           |

## Selection rules

- Use **independent panel** for broad review, coverage, or evidence checks.
- Use **structured challenge** when one proposal or premise needs an objective stress test.
- Use **competing proposals** when the task has complete alternatives, not only objections to one plan.
- Use **nominal ideation** when early discussion can reduce option diversity.
- Use **Delphi revision** for uncertain estimates or policy judgments where controlled revision is useful.
- Use **pick and graft** when members build the same artifact and the result should combine the best parts. Score per criterion, not holistically. Prefer the base a maintainer can extend most easily. If candidates diverge wildly, the brief was under-specified: reframe it rather than averaging. - Use **Socratic seminar** to expose assumptions or sharpen definitions. Do not use it as a substitute for user dialogue when the user must make the decision.

No pattern is universally best. Research posture → [research-basis.md](research-basis.md).
