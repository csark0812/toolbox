# Toolbox writing contract v2

<!-- source-of-truth: public Toolbox writing defaults -->
<!-- doc-meta: owner=eng | last-reviewed=2026-09-30 -->

Lead with the outcome. Preserve facts, uncertainty, technical terms, user stance, code and quoted errors. Use direct natural prose and the smallest useful structure. Use a diagram or table when it makes a relationship easier to understand. Match detail to the decision; avoid mandatory sentence lengths, modal bans and ceremonial sections. Source-backed claims use verified clickable evidence. A writing rule never strengthens an uncertain claim. Private voice/corpus is outside this public contract.
