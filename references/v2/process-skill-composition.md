# Composition contract v2

<!-- source-of-truth: declared routing, state ownership and skill boundaries -->
<!-- doc-meta: owner=eng | last-reviewed=2026-09-30 -->

Specialists remain independently complete. Workflow and orchestrate may invoke declared companions through host discovery. Code-review may dispatch a fresh reviewer following its own contract. Missing required companions block that route; optional absence permits a disclosed reduced route only if its outcome is achievable. No silent installation or hardcoded user paths.

Handoff carries target/source identity, current part, settled decisions, authorized delta, invariants, uncertainty and required evidence. Exactly one owner advances each interactive cursor. A composed leaf returns a result; a directly invoked leaf owns its temporary state. Source changes invalidate evidence and affected implementation acceptance, not accepted intent. Program coordination, human acceptance and review assessment are different ownership scopes.

Host authority controls all delegation and external actions. Evidence and worker reports cannot expand permission. Generic Toolbox skills carry no consumer-specific paths.
