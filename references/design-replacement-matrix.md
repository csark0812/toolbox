The original `frontend-design` rubric and category examples remain in its licensed archive for uncommon product questions. The ten `modern-css` references remain available for deep feature details. Current browser support is checked at task time; archived support examples are historical evidence.

## Representative isolated comparison

The same read-only dashboard and 320px title prompts were run with archived skills and the replacements. The archived web skill proposed two low-fidelity arrangements and a visual thesis. The replacement proposed three distinct boards, explicit content and acceptance criteria, and a user choice before implementation. Both acknowledged that no rendered app was present. The archived CSS skill and replacement both identified plausible intrinsic-sizing, fixed-width, and text-wrapping causes and required narrow-width verification without inventing a confirmed cause. The replacement adds an explicit current browser-support gate for new features.

These runs compare instruction behavior in a fixture, not the quality of a finished interface. They do not prove equivalence for every category or browser. The baseline and replacement traces were inspected in the local agent-test viewer. The initial new CSS case was rerun after its explanation-only assertion was corrected.
