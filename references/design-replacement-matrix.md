This matrix compares the original files preserved in [original-skills](original-skills/README.md) with the active Toolbox skills. It records an intentional scope change, not a claim that short instructions reproduce every example in the originals.

The original `frontend-design` rubric and category examples remain in its licensed archive for uncommon product questions. The ten `modern-css` references remain available for deep feature details. Current browser support is checked at task time; archived support examples are historical evidence.

## Representative isolated comparison

The same read-only dashboard and 320px title prompts were run with archived skills and the replacements of that time. The web comparison was against `interface-design`, since retired in favour of `taste`; its result no longer describes an active skill, and the isolated comparison suite has been removed. No archived-skill comparison has been run against `taste`. In the CSS comparison, the archived CSS skill and replacement both identified plausible intrinsic-sizing, fixed-width, and text-wrapping causes and required narrow-width verification without inventing a confirmed cause. The replacement adds an explicit current browser-support gate for new features.

These runs compare instruction behavior in a fixture, not the quality of a finished interface. They do not prove equivalence for every category or browser. The baseline and replacement traces were inspected in the local agent-test viewer. The initial new CSS case was rerun after its explanation-only assertion was corrected.
